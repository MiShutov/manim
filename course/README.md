# Тексты видео курса

Здесь лежат дословные тексты закадровой озвучки. Один файл — один ролик.
Файлы пронумерованы в порядке показа внутри раздела.


## Формат сценария

- Текст в цитатах (`>`) — то, что читается в микрофон.
- Всё остальное — режиссёрские пометки: что видно на экране, что держать,
  где сделать паузу.
- `[пауза]` — 0,5–1 с; `[акцент]` — интонационное выделение;
  `[сменить кадр]` — перейти к следующему визуальному состоянию.
- Ориентир по темпу — 130–140 слов в минуту. Длительности в шапках
  приблизительные: они нужны для планирования монтажа, а не для
  метронома.
- Английские подписи на экране не переводятся в речи механически:
  сначала смысл, затем термин. Например: «словарь, то есть таблица
  `id -> строка`», а не «vocabulary — это vocabulary».

## Синхронизация с анимацией

Сцены в репозитории — это анимационные схемы, а не монтажные листы.
Их суммарная длительность — десятки секунд, а текст рассчитан на
минуты. Это нормально: визуализация задаёт состояние, а не темп речи.

Рабочий приём:

1. Проиграйте анимацию до состояния, о котором идёт речь в блоке.
2. Остановите кадр и читайте текст.
3. Возобновите анимацию для перехода к следующему состоянию.

Если сцена должна идти непрерывно, можно добавить `self.wait()` в
соответствующем месте или замедлить `run_time`. Это не меняет
содержание диаграммы. Не ускоряйте речь под анимацию: визуализация
должна успевать за мыслью, а не наоборот.

## Произношение

Единого стандарта нет; ниже — нейтральный вариант, который не режет слух
в русской речи.

| На экране | В речи |
| --- | --- |
| `token` | «токен» |
| `token_id` | «ид токена» или «токен айди» |
| `embedding` | «эмбеддинг» |
| `lookup` | «лукап» |
| `encode` / `decode` | «энкод» / «декод» |
| `vocabulary` | «словарь»; английское слово — только если нужен акцент |
| `patch` | «патч» |
| `BPE` | «би-пи-и» |
| `SentencePiece` | «сентенс-пис» |
| `greedy` | «гриди», допустимо «жадный» |
| `byte-pair encoding` | «байт-пэйр энкодинг» |

## Термины, которые нельзя смешивать

- **Токен** — элемент последовательности, одна позиция на оси `T`.
  Не слово, не `token_id` и не вектор.
- **`token_id`** — целочисленный адрес токена в словаре. Категориальная
  метка; её величина не имеет смысла.
- **Эмбеддинг** — вектор, полученный из `token_id` выбором строки
  матрицы `E`. Это уже тензор, а не дискретный токен.
- **Словарь** — конечное отображение `id <-> строка`. Не список слов
  языка и не обучаемая матрица.
- **`encode` / `decode`** — прямое и обратное отображения токенизатора.
  Не путать с авторегрессионным декодированием LLM.
- **BPE** — частотный алгоритм слияний; результат обучения — не только
  словарь, но и упорядоченный список правил.
- **SentencePiece** — библиотека, реализующая BPE и unigram; в BPE-режиме
  работает с сырым текстом и мета-символом `▁`.
- **Патч** — область изображения, которая после проекции становится
  токеном последовательности.

## Редакционные правила

- Один блок — одна мысль и одно визуальное состояние.
- Не пересказывать цвет и геометрию, если они не несут смысла. Говорить,
  что означает элемент, а не какого он цвета.
- Не начинать каждый ролик с приветствия: приветствие живёт в отдельном
  вводном видео. Здесь — холодный старт с вопроса.
- Каждое утверждение о размерах, словарях и стоимости должно проверяться
  по коду сцены или по публичной карточке модели. Если меняются данные в
  `specs.py`, меняется и текст.
- Формулы и индексы — в LaTeX или в `code`, не простым текстом.
- Для следующих разделов: создавайте
  `course/<номер-раздел>/<номер-ролик>-<slug>.md` и добавляйте строку в
  таблицу выше.
