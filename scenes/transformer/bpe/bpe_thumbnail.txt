ОБЛОЖКА: BPE (SentencePiece)
ФАЙЛ: scenes/transformer/bpe/bpe_thumbnail.py
ВЫВОД: media/videos/bpe/thumbnail.png (1280x720)
КЛЮЧ: python scripts/thumbnails.py bpe

ЦЕЛЬ
-----
Превью для YouTube-видео по сцене bpe. Это не схема, а упаковка: один
кадр 16:9, который читается на размере 320x180 и обещает содержание
ролика — «BPE: как токенизатор учит subwords». Кадр должен совпадать по
визуальному языку со сценой, чтобы обложка и видео выглядели одним
продуктом, но масштаб элементов здесь крупнее: превью смотрят с
уменьшением, а не в полном размере.

КОМПОЗИЦИЯ
-----------
Две колонки: крупная типографика слева, одна панель-история справа.

Левая колонка (выровнена по левому краю x = -6.65):
- Надзаголовок «SUBWORD TOKENIZER» фиолетовым, bold, 30 pt.
- Гигантское «BPE» белым (#F0F6FC), bold, 210 pt: главный якорь кадра,
  занимает примерно четверть высоты.
- Под ним фиолетовая линия-подчёркивание во всю ширину слова, толщина 9,
  круглые концы. Она связывает надзаголовок и имя метода в один блок.
- Подзаголовок в две строки: «how a tokenizer» белым и «learns subwords»
  серым (muted), 46 pt. Вторая строка тише первой, чтобы не спорить с
  заголовком.
- Ниже фиолетовый пилюльный тег «SentencePiece»: заливка 0.14, обводка
  2.2, текст фиолетовым.

Правая панель (центр x = 3.62, поля 0.55 вокруг контента):
- Тёмная плашка #151B23 с обводкой #30363D, скругление 0.22. Ширина и
  высота не заданы константами: рамка строится по bounding box содержимого
  плюс 0.55 поля, поэтому она всегда обнимает текст и не выглядит великой.
- Внутри — только три уровня, выровненные по центру панели по вертикали:
  слово, стрелка, токены с id. Ни ряда символов, ни словаря, ни подписей:
  обложка обещает результат, а не пересказывает кадр.
- Сверху слово «lowest» зелёным mono, 52 pt: это вход, которого не было
  в корпусе.
- Зелёная стрелка вниз, толщина 16: одно и то же слово превращается в две
  части. Зелёный, а не фиолетовый, чтобы взгляд шёл по цепочке активаций
  «слово -> токены» без смены цвета; фиолетовый на обложке остаётся только
  за типографикой.
- Два зелёных токен-чипа «low» и «est» кеглем 52 pt — ровно как у слова
  сверху, поэтому видно, что это то же слово, разрезанное на две части.
  Мета-символ ▁ на обложке не показывается: он объясняется в видео и здесь
  только мешал бы читать «low» как часть «lowest».
- Под каждым токеном серый mono-чип с id: 1024 и 2048, по центру
  соответствующего токена.

ЦВЕТОВАЯ ГРАММАТИКА
--------------------
- Зелёный (activation): слово, стрелка слияния, токены.
- Фиолетовый (compute): надзаголовок, подчёркивание, тег SentencePiece.
- Белый (text): «BPE» и первая строка подзаголовка.
- Серый (muted): вторая строка подзаголовка, id токенов.
- Жёлтый (weights) не используется: в BPE нет обучаемых матриц.

РАСКАДРОВКА
------------
Кадр статический; анимация нужна только для того, чтобы при полном
рендере получался короткий ролик-заставка:
1. Панель.
2. Надзаголовок, «BPE», подчёркивание, подзаголовок, тег.
3. Слово «lowest».
4. Стрелка.
5. Токены.
6. Id токенов.

ОГРАНИЧЕНИЯ
------------
- Никаких индексов и формул простым текстом: на обложке их нет вообще,
  кроме id токенов (это строки данных, mono-текст допустим).
- Шрифты только из темы: Inter для типографики, DejaVu Sans Mono для
  токенов и id.
- Все цвета — семантические ключи темы, ни одного литерального цвета.
- Стрелка здесь зелёная, а не фиолетовая: это осознанное отступление от
  грамматики схем (там фиолетовый — вычисление). На обложке стрелка
  связывает слово и его токены, то есть две активации, и держит правую
  панель в одном цвете.
- Слово и оба токена набраны одним кеглем 52 pt: равенство размеров и есть
  сообщение «это одно и то же слово».
- Отступ от края кадра не меньше 0.5 юнита: YouTube обрезает края при
  показе в некоторых плейсхолдерах.
- Нижний правый угол свободен: там YouTube рисует длительность ролика.
- Один кадр — одна мысль: слово и два токена. Ни корпуса, ни правил, ни
  словаря: их видно в самом видео.
