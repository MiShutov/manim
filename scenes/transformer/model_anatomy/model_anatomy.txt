СЦЕНА: Transformer-decoder architecture (анатомия модели)
ФАЙЛ: scenes/transformer/model_anatomy/model_anatomy.py
КЛЮЧ: python scripts/render.py model_anatomy -q l

ЦЕЛЬ
-----
Показать архитектуру Transformer-декодера одной горизонтальной картинкой:
текст -> токены -> функция Embedding (взятие эмбеддинга по id, без матрицы
весов) -> token embeddings -> один широкий блок Transformer -> ряд из N
блоков Block с многоточием -> hidden states -> фиолетовый блок матмула с
W_lm_head -> logits.

ВИЗУАЛЬНАЯ ГРАММАТИКА
---------------------
- Фиолетовый (compute): блок Embedding, блоки Block, блок матмула lm_head,
  многоточие, подпись под фигурной скобкой.
- Зелёный (activation / dimension): token embeddings / hidden states, logits,
  формы тензоров, номера блоков 1/2/N.
- Жёлтый (weights): только W_lm_head внутри блока матмула.
- Серый (muted): нейтральные стрелки, подписи.
- Легенда обозначений: слева внизу, чтобы не мешать верхнему потоку
  prompt -> tokens и основной линии архитектуры.

ВЫРАВНИВАНИЕ
------------
- Все элементы основной линии стоят на одном центре MAIN_Y = 0:
  блок Embedding, матрица активаций, блоки Block, hidden states, блок
  матмула, logits.
- Подписи слева идут двумя общими рядами NAME_Y и SHAPE_Y.
- Все стрелки строго горизонтальные или вертикальные, без диагоналей.
- Чипы токенов и фраза центрированы над блоком Embedding.

МАТЕМАТИЧЕСКИЕ ОБОЗНАЧЕНИЯ
--------------------------
- Функция эмбеддинга подписана по имени: x_i = Embedding(id_i) (LaTeX).
- Промежуточная активация: token embeddings = (B, S, d_model); после
  появления Transformer она называется hidden states.
- Выход стека — изменённое hidden states, помеченное штрихом: hidden states′.
- Блок матмула подписан как h′ @ W_lm_head: W_lm_head жёлтый (обучаемый
  вес), результат — logits (B, S, vocab).
- N — число блоков: индексы 1, 2, N и фигурная скобка
  "N transformer blocks".
- Только LaTeX, без plain-текста вида d_model или vocab.

ДАННЫЕ
------
Промпт: "The cat is sleeping", 5 токенов.
Token_ids под токенами: 464, 3797, 318, 5396, 278 (компактный ряд).
Матрица активаций: 5 строк (S, по токену) x 4 столбца (d_model), зелёная;
строка токена "cat" подсвечена и связана Indicate с чипом "cat".

РАСКАДРОВКА
-----------
1. Заголовок "Transformer-decoder architecture" и легенда слева внизу.
2. Фраза "The cat is sleeping"; стрелка вниз, чипы токенов появляются.
3. Под токенами появляются token_ids (компактный ряд, mono).
4. Стрелка вниз в блок Embedding; появляется фиолетовый блок с формулой.
5. Подпись "embedding" и Indicate блока.
6. Стрелка к зелёной матрице token embeddings; подпись "token embeddings"
   и форма (B, S, d_model); подсветка связки "chip 'cat' -> строка X".
7. Появляется широкий фиолетовый блок "Transformer"; кубики token embeddings
   превращаются в зелёный блок "hidden states" (B, S, d_model) — такой же,
   как на выходе стопки; подписи "token embeddings" и формы исчезают,
   их заменяет сам блок.
8. Блок уходит влево и растворяется в первом Block; справа с лагом
   появляются ещё два Block, многоточие и номера 1, 2, N.
9. Блоки чуть раздвигаются; появляются стрелки между ними.
10. После блоков появляется зелёный блок "hidden states′" (B, S, d_model);
    штрих показывает, что состояние изменилось относительно входа.
11. Далее фиолетовый блок h′ @ W_lm_head (W жёлтый) и подпись "lm_head".
12. На выходе зелёный блок "logits" (B, S, vocab).
13. Фигурная скобка под блоками с подписью "N transformer blocks".
14. Финальные Indicate трёх частей: embeddings, blocks, output head.

ОГРАНИЧЕНИЯ
-----------
- Блоки в стопке подписаны "Block"; широкий входной блок — "Transformer".
- Подписи "Block", "hidden states" и "logits" одного кегля (badge_title).
- Выход стека помечать штрихом (hidden states′); вход — без штриха.
- Не рисовать матрицу весов эмбеддингов: только функция Embedding по имени.
- Не использовать бегающий шарик/линию сигнала: архитектура статична.
- Не рисовать d_model / vocab / W простым текстом: только LaTeX.
- W_lm_head всегда жёлтый, активации зелёные.
- Ровно 1, 2, ..., N: средние блоки заменены одним многоточием.
- Легенду держать на левом краю.
- Внутри Block не добавлять детализацию (attention/FFN) — есть отдельная
  сцена llama_block.
