СЦЕНА: Transformer block — forward и swap-in модификации
ФАЙЛ: scenes/transformer/block_modifications/block_modifications.py
КЛЮЧ: python scripts/render.py block_modifications -q l

ЦЕЛЬ
-----
Показать один transformer block (LlamaDecoderLayer) как компактный граф
вычислений без рамки: вход x -> Normalization -> Self-attention -> ⊕ ->
Normalization -> MLP -> ⊕ -> выход x'. Forward разбирается построчным
Python-псевдокодом, выполнение показывается коротким импульсом блока.
Затем по одной демонстрируются замены в порядке: нормализации, attention,
MLP, и в самом конце — mHC (фиолетовые блоки в residual-ветках). Блок всё
время стоит по центру экрана; при раздвижке он растёт симметрично вверх и
вниз, сохраняя центр. В финале блок сдвигается в центр и по горизонтали.

ВИЗУАЛЬНАЯ ГРАММАТИКА
---------------------
- Фиолетовый (compute): Normalization, Self-attention, MLP, router и
  эксперты, блоки mHC.
- Зелёный (activation / dimension): бейджи x и x', формы, ячейки маски.
- Оранжевый (residual): ⊕ и residual-ветки, обходящие блок.
- Жёлтый (weights): активация экспертов и маршрутов в MoE.
- Серый (muted): стрелки, нотация, ссылки.

ГЕОМЕТРИЯ ОСНОВНОГО БЛОКА
--------------------------
- Колонка x = -2.2; узлы 1.8 x 0.34, бейджи 1.7 x 0.44; шрифты: заголовки
  блоков и карточек badge_title (17), формы 13, псевдокод 14, нотация 10–13.
  Рамки нет.
- Входной бейдж приподнят: зазор до первого Normalization 0.36 (INPUT_GAP),
  остальные зазоры 0.18.
- _layout центрирует блок по вертикали: offset = -(верх + низ)/2, поэтому
  схема стоит посередине, а при росте панелей верх/низ расходятся
  симметрично. В конце сцена сдвигает блок в центр и по горизонтали.
- Сверху вниз: x, Normalization, Self-attention, ⊕, Normalization, MLP, ⊕, x'.
- Все стрелки одной толщины; residual начинается на вертикальной стрелке,
  уходит влево на шину x=-3.65 и входит в ⊕ слева.
- Нотация — слева сверху: B, T / d_model / ⊕.
- Псевдокод — справа (x=1.0), шаг строк 0.30.
- Подписи замен — справа, на середине по высоте (x=1.7, y=0.58/0.34).

ПСЕВДОКОД
----------
def forward(x):
    residual = x
    x = norm(x)
    x = self_attn(x)
    x = residual + x

    residual = x
    x = norm(x)
    x = mlp(x)
    x = residual + x
    return x

РАСКАДРОВКА
------------
1. Заголовок по центру, блок, вход x, узлы, стрелки, residual-ветки, выход x',
   псевдокод и нотация слева сверху.
2. Forward: строка подсвечивается, блок/⊕/ветка импульсно увеличивается
   (Indicate). Финал — Flash на x'. Псевдокод исчезает.
3. Нормализации:
   - Normalization -> LayerNorm -> RMSNorm -> Normalization;
   - Gemma 4: старые блоки Normalization убираются (fade out), вместо них
     появляются 4 маленьких «norm» поверх стрелок (непрозрачная заливка,
     стрелка за блоком) и QK-norm внутри attention; QK-блоки сдвинуты
     вправо от надписи Self-attention. Ссылка: arXiv:2607.02770.
4. Attention: Self-attention -> causal mask -> windowed attention -> GDN ->
   Self-attention. Сетка маски и формула/легенда стоят на одних и тех же
   координатах, поэтому при causal -> windowed ничего не «ездит».
   - windowed: локальное окно; arXiv:2310.06825 (Mistral 7B);
   - GDN: S_{t-1} -> блок «g_t» -> S_t, петля состояния (без отдельной
     жёлтой g_t со стрелкой); arXiv:2412.06464.
5. MLP -> MoE: MLP раскрывается в вертикальную панель:
   широкий router -> 3 стрелки вниз -> Expert 1/2/3 -> центр: толстая
   стрелка в ⊕, бока: угловые стрелки в бока ⊕ -> выход вниз. Анимация:
   router срабатывает, жёлтым подсвечиваются эксперты, стрелки от router
   и стрелки из них в ⊕: (1,3), затем (2,3), затем (1,2).
   arXiv:1701.06538.
6. mHC (в самом конце): в обе residual-ветки вставляются фиолетовые блоки
   mHC на шине x=-3.65, residual подсвечивается. arXiv:2512.24880.
   Большая четырёхпоточная схема mHC сохранена отдельно в mhc_diagram.py
   (не используется этой сценой).
7. Финал: блок без модификаций сдвигается в центр кадра, wait(1).

ОГРАНИЧЕНИЯ
------------
- Не использовать бегущий шарик: выполнение — только Indicate.
- Все стрелки одной толщины; residual выходит только из стрелок.
- Вход и выход блока всегда одной формы (B, T, d_model).
- Forward без kv-cache, масок и position_ids.
- Каждая модификация показывается отдельно и откатывается назад.
- Подписи с индексами (d_model, S_{t-1}, x', x'') — только LaTeX.
- Цвета — только семантические ключи темы, без хардкода.
