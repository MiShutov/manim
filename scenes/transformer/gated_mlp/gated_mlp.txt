СЦЕНА: Gated MLP (SwiGLU)
ФАЙЛ: scenes/transformer/gated_mlp/gated_mlp.py
КЛЮЧ: python scripts/render.py gated_mlp -q l

ЦЕЛЬ
-----
Разобрать базовый gated MLP из Llama как явный граф вычислений:

    g = x @ W_gate
    u = x @ W_up
    h = act_fn(g) * u
    y = h @ W_down

Блок сразу рисуется вместе с forward-псевдокодом и всеми промежуточными
размерностями. Затем generic act_fn заменяется на SiLU, заголовок меняется
на "SwiGLU", а справа появляется формула SiLU. В конце сцена очищается и на
матричном примере показывается, что каждый элемент выхода зависит только от
одной строки входа и одного столбца весов, а строки X и G соответствуют
одним и тем же токенам.

ВИЗУАЛЬНАЯ ГРАММАТИКА
---------------------
- Фиолетовый (compute): вычислительные блоки gate_proj/up_proj/down_proj,
  ACT_FN/SiLU, поэлементное умножение, матричное умножение @.
- Фиолетовый (complexity): итоговая сложность O(...).
- Зелёный (activation): вход x, активации g/u/h/y, строки токенов,
  промежуточные формы (B, S, d_model) и (B, S, d_ff).
- Жёлтый (weights): обучаемые матрицы W_gate, W_up, W_down.
- Белый: формулы, forward-код, рамка блока и структурные подписи.
- Стрелки: нейтрально-серые, одинаковая толщина и наконечник.
- Легенда Notation: слева, чтобы не занимать вертикаль над графом.

ТИПОГРАФИКА
------------
- Все заголовки блоков используют один размер badge_title.
- Зелёные карточки тоже используют MathTex (title_tex=True), а не жирный
  Text: иначе они выглядят крупнее и тяжелее фиолетовых блоков.
- Ширины блоков подогнаны под содержимое, без больших пустых полей.

МАТЕМАТИЧЕСКИЕ ОБОЗНАЧЕНИЯ
--------------------------
- Матричное умножение: @ (в LaTeX: \mathbin{@}).
- Поэлементное умножение: \odot. Скалярное произведение и размерные
  произведения: \cdot.
- Все индексы и нижние индексы только в LaTeX: d_model, d_ff, W_gate,
  W_up, W_down, x_i, g_i, y_i, g_{i,j}, x_{i,k}, w_{k,j}.
- W — обучаемые параметры, поэтому жёлтый.
- attn-подобных матриц здесь нет: MLP не смешивает токены.
- В легенде: B, S (batch, sequence), d_model (hidden), d_ff
  (intermediate), σ (activation function), W (learned weights),
  @ (matrix product), ⊙ (element-wise product).

ДАННЫЕ
------
B = batch size, S = sequence length.
Llama 3 8B: d_model = 4096, d_ff = 14336.

Формы:
  вход x:                 (B, S, d_model)
  g = x @ W_gate:         (B, S, d_ff)
  u = x @ W_up:           (B, S, d_ff)
  ACT_FN(g) / SiLU(g):    (B, S, d_ff)
  h = σ(g) ⊙ u:           (B, S, d_ff)
  y = h @ W_down:         (B, S, d_model)
  выход y:                (B, S, d_model)

Веса:
  W_gate, W_up:           (d_model, d_ff)
  W_down:                 (d_ff, d_model)

Сложность:
  total: O(B · S · d_model · d_ff)

ГЕОМЕТРИЯ ОСНОВНОГО БЛОКА
-------------------------
- Рамка блока: x от -2.05 до 2.05, y от -1.75 до 3.55.
- Вход x: (0, 3.14), ширина 1.35.
- Две ветви: gate_proj слева (x=-0.90), up_proj справа (x=0.90),
  y=2.40, ширина 1.70.
- Карточки g и u: y=1.66, ширина 1.00.
- ACT_FN/SiLU: y=0.92, только на gate-ветви, ширина 1.85; заголовок
  σ(g) = ACT_FN(g), после замены σ(g) = SiLU(g).
- Поэлементное умножение h = σ(g) ⊙ u: (0, 0.18), ширина 1.80.
- down_proj: (0, -0.56), ширина 1.90.
- Выход y: (0, -1.30), ширина 1.55.
- Справа, вне рамки: панель forward-кода.
- Ниже неё: панель SiLU с формулами SiLU(x) = x · σ(x) и
  σ(x) = 1 / (1 + e^{-x}).
- Внизу: итоговая сложность и конкретные размерности Llama 3 8B.
- Легенда Notation слева, x = -6.85.

FORWARD-КОД
------------
def forward(x):
    x = self.down_proj(
        self.act_fn(self.gate_proj(x))
        * self.up_proj(x)
    )
    return x

Код показывается в начале сцены, когда впервые рисуется граф, и исчезает
вместе с блоком перед матричным примером.

РАСКАДРОВКА
-----------
1. Появляются заголовок "Gated MLP", легенда, рамка блока и панель
   forward-кода.
2. Вход x появляется сразу с формой (B, S, d_model).
3. Две диагональные стрелки к gate_proj и up_proj. Блоки
   g = x @ W_gate и u = x @ W_up появляются сразу с формой (B, S, d_ff);
   W_gate/W_up внутри заголовков жёлтые.
4. Стрелки вниз к зелёным карточкам g и u с их формами.
5. На gate-ветви появляется блок σ(g) = ACT_FN(g) с формой; на up-ветви
   активации нет.
6. Появляется блок h = σ(g) ⊙ u с формой (B, S, d_ff); обе ветви
   входят в него сверху.
7. Стрелка к down_proj y = h @ W_down с формой (B, S, d_model), затем к
   зелёному выходу y с формой (B, S, d_model).
8. Внизу появляется total O(B · S · d_model · d_ff) и
   Llama 3 8B: d_model = 4096, d_ff = 14336.
9. SwiGLU: заголовок σ(g) = ACT_FN(g) превращается в σ(g) = SiLU(g),
   блок h = σ(g) ⊙ u сохраняется, заголовок "Gated MLP" — в "SwiGLU".
   В панели справа появляются формулы SiLU и сигмоиды.
10. Сцена очищается. Появляется только заголовок "The MLP is position-wise".
11. Слева появляется матрица X формы (B · S, d_model): строки — это токены
    (b_i, s_i). В центре — жёлтая матрица W_gate формы
    (d_model, d_ff). Справа — почти пустая матрица G формы
    (B · S, d_ff). Между X и W стоит @, между W и G стоит =.
12. Снизу выводится формула
    g_{i,j} = Σ_k x_{i,k} · w_{k,j}.
13. Поэлементный проход ровно по одной выходной строке (i = (b_0, s_1)):
    для каждого столбца j подсвечиваются:
    - строка i матрицы X;
    - столбец j матрицы W;
    - элемент (i, j) матрицы G.
    Остальные строки и столбцы притухают, выбранный элемент G
    заполняется. Так видно, что один выходной элемент использует ровно одну
    строку X и один столбец W.
14. После полного прохода по строке остальные строки G сразу показываются
    заполненными: для них действует та же операция, но поэлементная
    анимация больше не повторяется. Выводятся три тезиса:
    - g_{i,j} depends only on row i of X;
    - no other token i' != i enters this element;
    - the sequence position s only names the row; it never enters the math.
15. W, @, = и поэлементная формула исчезают. Строки X и G немного
    раздвигаются по вертикали; заголовки и подписи тоже разъезжаются, чтобы
    не пересекаться с матрицами.
16. Тонкие горизонтальные стрелки соединяют каждую строку X с той же
    строкой G. Над промежутком остаётся подпись "same token i".
17. Блок MLP возвращается на экран (уже SwiGLU). Белая мелкая подпись:
    "matrix products dominate the graph". Последовательно подсвечиваются
    три проекционных блока — единственные матричные умножения в графе.
18. В конце остаётся только per-token формула:

    y_i = ( SiLU(x_i @ W_gate) ⊙ (x_i @ W_up) ) @ W_down

    y_i, x_i зелёные, W_* жёлтые, SiLU фиолетовый.

ОГРАНИЧЕНИЯ
-----------
- Не писать d_model, d_ff, W_gate, x_i, y_i простым текстом.
- Не красить блоки в цвета вне семантической палитры.
- Не переносить легенду наверх.
- Не использовать concat/reshape/transpose: в MLP их нет.
- Не возвращать отдельную панель learned weights: формы весов уже видны
  из заголовков проекций.
- Не добавлять подзаголовок про hidden states под "The MLP is
  position-wise".
- В матричном примере элемент G(i, j) соответствует строке i матрицы X и
  столбцу j матрицы W; нельзя подсвечивать строку/столбец с другим индексом.
- После матричного примера строки X и G не перемешиваются: они только
  раздвигаются, затем соединяются тонкими стрелками.
- В финале остаётся только формула y_i; forward-код показывается только
  в начале сцены.
