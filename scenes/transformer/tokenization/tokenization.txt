СЦЕНА: Tokenization
ФАЙЛ: scenes/transformer/tokenization/tokenization.py
КЛЮЧ: python scripts/render.py tokenization -q l

ЦЕЛЬ
-----
Показать, что токенизатор — это обратимое отображение текста в
последовательность token_id и обратно, и что оба направления работают
через один большой словарь (JSON-таблицу) token_id -> строка.

Пример: "The cat is sleeping." -> The | cat | is | sleep | ing | .
Token ids: 464, 3797, 318, 5396, 278, 13.
Обратный проход tokenizer.decode(ids) возвращает исходный текст
"The cat is sleeping.".

ВИЗУАЛЬНАЯ ГРАММАТИКА
---------------------
- Фиолетовый (compute): блоки tokenizer.encode / tokenizer.decode,
  имена функций в строках кода.
- Зелёный (activation / dimension): текст, токены, строки словаря,
  направление поиска, формула round-trip.
- Серый (muted): token_id, пунктуация JSON, подписи, нейтральные
  стрелки, скроллбар.
- Жёлтый (weights) в сцене не используется: токенизатор не обучаемая
  матрица, а фиксированный словарь.
- Успешный round-trip отмечается зелёной галочкой и подписью same text.

КОМПОЗИЦИЯ
-----------
Левая часть (примерно 2/3 экрана) — петля кодирования и декодирования:
- input text: карточка слева сверху, центр (-5.85, 1.75);
- tokenizer.encode: фиолетовый блок, центр (-3.00, 1.75);
- tokens: ряд зелёных чипов справа сверху, центр (0.45, 1.75);
- token ids: ряд серых mono-чипов под токенами, центр (0.45, 1.22);
- tokenizer.decode: фиолетовый блок под ids, центр (0.45, 0.25);
- decoded text: карточка слева снизу, центр (-5.85, 0.25);
- под петлёй: формула decode(encode(x)) = x и подпись
  round-trip identity (y ≈ -1.75).

Стрелки:
- text -> tokenizer.encode (горизонтальная);
- tokenizer.encode -> tokens (горизонтальная);
- ids -> tokenizer.decode (вертикальная);
- tokenizer.decode -> decoded text (длинная горизонтальная обратно
  влево, замыкает петлю).

Строки кода (mono, подсветка синтаксиса):
- над encode-петлёй: ids = tokenizer.encode(text);
- над обратной стрелкой: text = tokenizer.decode(ids).
Строки кода не пересекают блоки и не заходят на заголовок.

Правая часть (примерно 1/3 экрана) — панель словаря:
- рамка по центру x = 4.80, ширина 4.40, высота 6.96;
- заголовок vocabulary.json слева, |V| ≈ 100,256 справа;
- словарь в ОДНУ колонку: JSON-записи "token_id": "string";
- видимое окно панели: top 2.78, bottom -2.38;
  строки вне окна полностью скрыты масками, а на границе окна
  обрезаются ровно по краю, как в настоящем редакторе;
- справа тонкий скроллбар с подвижным бегунком;
- под окном направление encode: string -> id / decode: id -> string
  и подпись ... more entries;
- таблица длиннее окна: в ней 38 строк, включая 10 строк примера и
  служебные строки до/после них.

СЛОВАРЬ
-------
SCROLL_VOCAB (отсортирован по token_id):
  прелюдия: 1..12 (короткие служебные куски);
  окно примера: 13 ".", 262 "the", 278 "ing", 318 "is", 319 "on",
    464 "The", 2603 "mat", 3797 "cat", 5396 "sleep", 7623 "sofa";
  продолжение: 8001 "so" ... 100255 "...".
Для шести токенов примера записи подсвечиваются; остальные остаются
нейтральными decoy-записями. Счётчик 100,256 показывает реальный
порядок размера словаря, хотя на экране только окно в него.

РАСКАДРОВКА
-----------
1. Заголовок "Tokenization: text to tokens and back".
2. Слева сверху появляется карточка input text с фразой и подписью
   input text.
3. Появляются строка ids = tokenizer.encode(text), фиолетовый блок
   tokenizer.encode(text) и подпись encode. Стрелка ведёт от текста
   к блоку.
4. Из блока по одному появляются токены The, cat, is, sleep, ing, .;
   под ними синхронно появляются token ids. Над парой sleep + ing
   появляется скобка с подписью sleeping: одно слово разрезано на два
   subword-токена. Справа от рядов появляются подписи tokens и ids.
5. Справа появляется панель vocabulary.json: рамка, заголовок,
   счётчик, разделитель, направление encode: string -> id, скроллбар
   и видимое окно с 13 строками. Строки выше и ниже окна погашены.
6. Прокрутка: бегунок скроллбара едет вниз, таблица уезжает вверх;
   строки исчезают за верхней границей окна и появляются из нижней,
   обрезаясь ровно по краю, как в редакторе. В окне проходят id вплоть
   до 100255. Затем прокрутка возвращается в окно примера, бегунок едет
   обратно вверх. Это показывает, что словарь намного больше окна.
7. Encode lookup: для каждого токена по очереди подсвечиваются его чип,
   его token_id и соответствующая запись словаря. Подсветка записи
   остаётся после анимации.
8. Появляется строка text = tokenizer.decode(ids), фиолетовый блок
   tokenizer.decode(ids) и подпись decode. Вертикальная стрелка идёт
   от ids к блоку.
9. Длинная стрелка возвращается от decode к decoded text; карточка
   decoded text появляется с исходной фразой. Между входной и выходной
   карточками появляется зелёная галочка same text.
10. Направление в панели меняется на decode: id -> string. Для
    каждого id по очереди подсвечиваются id-чип и строка значения в
    словаре: видно, что decode ищет строку по id.
11. Внизу слева появляется формула decode(encode(x)) = x с подписью
    round-trip identity.
12. Финальный кадр: вся петля text -> ids -> text, панель словаря с
    шестью подсвеченными записями, счётчик, скроллбар и направление.
    Небольшой wait, затем сцена заканчивается.

ОГРАНИЧЕНИЯ
-----------
- Левая петля занимает примерно 2/3 ширины, правая панель — 1/3.
- Словарь строго в одну колонку.
- Не использовать token_id / tokenizer.encode / vocabulary простым
  текстом там, где нужен код: код идёт mono-шрифтом.
- Фиолетовый только у блоков tokenizer.encode/decode и имён функций.
- Строки словаря всегда зелёные, token_id всегда серые.
- Словарь не должен выглядеть как обучаемая матрица: никакого W и
  жёлтого цвета.
- Стрелки только горизонтальные/вертикальные, без диагоналей.
- Encode-подсветка идёт string -> id, decode-подсветка идёт id -> string.
- Счётчик словаря не равен числу видимых строк: видимое окно — около
  13 строк, подпись — 100,256.
- Прокрутка обязательна: она должна показать строки далеко за пределами
  окна примера и вернуться назад.
- Строки вне окна не должны быть видны: их закрывают маски, и на
  границе окна строка обрезается, как в настоящем JSON-редакторе.
- Панель словаря не перекрывает левую петлю.
