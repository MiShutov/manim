СЦЕНА: Transformer-decoder autoregressive generation
ФАЙЛ: scenes/transformer/generation_loop/generation_loop.py
КЛЮЧ: python scripts/render.py generation_loop -q l

ЦЕЛЬ
-----
Продолжить сцену model_anatomy и показать авторегрессионную генерацию без
KV-кэша: фиксируем B = 1 и S = 5, проходим форвард-пасс, получаем логиты по
словарю из 10 токенов, выбираем argmax, добавляем его id в контекст, кормим
обратно и повторяем. В финале в контексте 7 токенов.

СТАРТ
-----
Первый кадр повторяет финальный кадр model_anatomy (плюс token_ids под
токенами): Embedding lookup, hidden states, N блоков Block, hidden states′,
матмул h′ @ W_lm_head, logits. Сверху появляется новый заголовок.

ВИЗУАЛЬНАЯ ГРАММАТИКА
---------------------
- Фиолетовый (compute): Embedding, блоки Block, матмул lm_head, скобка.
- Зелёный (activation): hidden states, logits, token-embeddings, формы,
  значения score, индексы 1/2/N.
- Жёлтый (weights): W_lm_head.
- Серый (muted): token_ids, стрелки, подписи, легенда, карточки словаря.
- Карточка-победитель argmax подсвечивается зелёным контуром и заливкой.

ВЫРАВНИВАНИЕ
------------
- В начале сцены весь контент (кроме заголовка) плавно опускается на 0.40.
- Основная линия архитектуры: MAIN_Y = -0.15, все элементы на одной высоте.
- Ряд слов — WORD_Y = 1.95, ряд token_ids — ID_Y = 1.25.
- Строка настроек B/S — SETTINGS_Y = 2.45, заголовок — 3.78.
- Словарь — таблица 5 x 2 карточек в рамке над пайплайном; от logits к
  правой границе рамки идёт ортогональная стрелка.
- Легенда прижата к диаграмме: заголовок -1.45, строки с -1.75.

МАТЕМАТИЧЕСКИЕ ОБОЗНАЧЕНИЯ
--------------------------
- B = 1 (one prompt): в батче один текст.
- S = 5 (five prompt tokens): в промпте пять токенов; затем S = 6, S = 7.
- Формы: hidden states (1, S, d_model); логиты (1, S, vocab).
- score = logit; победитель — argmax по словарю.
- Новый токен — hidden states′ в формуле h′ @ W_lm_head.
- Все индексы и размерности только в LaTeX.

ДАННЫЕ
------
Промпт: "The cat is sleeping" -> The cat is sleep ing.
token_ids: 464, 3797, 318, 5396, 278.
Словарь (10): The 464, cat 3797, is 318, sleep 5396, ing 278,
on 319, the 262, sofa 7623, mat 2603, . 13.
Раунд 1: максимум on (319), score 6.2.
Раунд 2: максимум the (262), score 6.6.
Итог: The cat is sleep ing on the (7 токенов).

РАСКАДРОВКА
-----------
1. Статичный стартовый кадр: архитектура, слова с id, скобка, легенда.
   Весь контент плавно опускается вниз на 0.40.
2. Появляется строка B = 1 (one sequence) · S = 5 (five tokens in a
   sequence). Пять пар "слово + id" подсвечиваются по очереди.
3. Символьные формы (B, S, ...) заменяются на (1, 5, ...); hidden states
   подсвечивается.
4. Форвард-пасс: подсветка идёт по token_ids -> Embedding -> hidden states ->
   Block -> Block -> Block -> hidden states′ -> lm_head -> logits.
5. Над пайплайном появляется рамка с таблицей vocabulary из 10 карточек
   (текст + token_id); от logits к правой границе рамки идёт стрелка.
   Затем у каждой карточки появляется score = logit.
6. Карточка с максимальным score подсвечивается; её token_id вылезает из
   таблицы (из своей карточки) и уезжает влево в ряд token_ids.
7. От нового id вверх идёт стрелка, появляется слово, стрелка исчезает;
   вниз идёт маршрутная стрелка в Embedding.
8. S меняется 5 -> 6: формы обновляются, hidden states и его строка формы
   подсвечиваются; идёт второй форвард-пасс.
9. Scores обновляются под второй раунд, подсвечивается the; его id 262
   так же вылезает из таблицы и уплывает в ряд token_ids, появляется
   слово the.
10. S меняется 6 -> 7, формы (1, 7, ...) подсвечиваются.
11. Финал: 7 слов, 7 id, многоточие "…" справа; таблица и подсветка
    победителя остаются на экране.

ОГРАНИЧЕНИЯ
-----------
- Не использовать бегающий шарик: только последовательные Indicate.
- B и S только в LaTeX; не писать d_model / vocabplain-текстом.
- Таблица vocabulary всегда сверху в рамке; новый token_id вылезает из
  карточки-победителя, а не появляется из края экрана.
- Стрелки в Embedding — ортогональные (route_arrow), без диагоналей.
- В финале ровно 7 токенов; продолжение обозначено "…".
- Легенду держать на левом краю.
